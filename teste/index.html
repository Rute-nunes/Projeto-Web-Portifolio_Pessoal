Use a tag a com os atributos href e download. href: Contém o caminho ou URL do arquivo que você quer que o usuário baixe. Se o arquivo estiver na mesma pasta do seu arquivo HTML, basta colocar o nome dele. Caso contrário, use o caminho completo (ex: documentos/meu_arquivo.pdf). download: Este atributo é o que faz o navegador entender que o link deve ser baixado, e não exibido. Você pode até dar um novo nome ao arquivo, assim: download="novo_nome.pdf".
